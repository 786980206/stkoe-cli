🕸️ stkoe 资产血缘图查看器

⚠️ 直接以 file:// 打开时浏览器禁止 fetch，请用静态服务： python -m http.server 8080 --directory tools/graph-viewer，或直接把 JSON 拖进页面。

资产类型

—

把 graph-data.json（或任意本工具导出的 JSON）拖到这里
也可以 点击选择文件
1️⃣ 先导出数据：python tools/graph-viewer/export.py <graph.db> [--node table:index] [--depth 3] --output graph-data.json
2️⃣ 再启动服务：python -m http.server 8080 --directory tools/graph-viewer，浏览器打开 http://127.0.0.1:8080/（也可 ?data=xxx.json 指定数据文件）
3️⃣ 交互：单击节点看详情；选中节点自动高亮上游（琥珀）与 下游（青）；图例点击可隐藏类型；支持多种布局。
